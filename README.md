Это проект по работе с напоминаниями в телеграме на основе ИИ.
Нейросеть получает сообщение пользователя, определяет к чему отнести сообщение: **Напоминание**, **Задача**, **Удаление напоминания/задачи**, **Обычный диалог** и отвечает пользователю.

В качестве нейросети используются API-эндпоинты OpenAI.

Так же, есть привязка к Google-Календарю при помощи сервисного аккаунта.
